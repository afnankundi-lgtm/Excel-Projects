# 📊 Excel Revenue Dashboard

An Excel-based data analytics project that transforms **raw data into clean data, analysis, visualizations, and business insights**.

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Analysis → Visualization → Insights**

## 🧹 Data Cleaning

* TRIM & PROPER for text cleaning
* Date formatting
* Missing value handling
* Mean, Median & Mode for appropriate data

## 📈 Analysis

* Pivot Tables
* Revenue analysis
* Category comparison
* Pattern identification

## 📊 Dashboard

* Pie Chart
* Line Chart
* Bar Chart
* Column Chart

## 🛠️ Tools & Skills

**Microsoft Excel • Data Cleaning • Pivot Tables • Data Analysis • Data Visualization • Dashboard Development**

* `Revenue_Dashboard.xlsx` — Final Excel dashboard

## 🎯 Goal

To demonstrate a practical **Excel data analytics workflow** from raw data to business insights.
